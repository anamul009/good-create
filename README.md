# Good Create — corporate website

Redesign of the Good Create Co., Ltd. corporate site (株式会社グッドクリエイト), built with Astro.

- **Source:** [`site/`](site/) — see [`site/README.md`](site/README.md) for structure, content files and open items.
- **Preview:** published automatically to GitHub Pages on every push to `main` (`.github/workflows/pages.yml`). The preview is marked `noindex`.

```bash
cd site
npm install
npm run dev
```
